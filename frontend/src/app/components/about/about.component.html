SYSTEM DESIGN & ARCHITECTURE

Built for Scale, Zero Cost Latency & Automation.

JobTrackerPro is an enterprise-grade full-stack platform engineered to demonstrate advanced system design, cloud-native scalability, and resilient data processing. From real-time event-driven Gmail webhooks and hybrid deterministic/AI parsing, to in-memory Caffeine caching and fine-grained Angular Signals.

View Source on GitHub Try Live Demo

Why I Built This

Searching for a job is an intensive endeavor. Spreadsheets are notoriously messy, prone to stale data, and unable to capture the real-world progression of interview stages, recruiter contacts, and timeline notes without constant manual upkeep.

Rather than building a basic CRUD tutorial, I architected JobTrackerPro as a production-grade, event-driven platform. It operates hands-free: users connect their Gmail or forward confirmation emails, and the system autonomously ingests, normalizes, deduplicates, and manages their entire interview pipeline in real time.

End-to-End Pipeline

4-Phase System Architecture

Decoupled · Event-Driven · Low-Latency
Phase 01 · Ingestion Layer

Automated Webhooks & Gmail Push

Users link their Gmail account via OAuth2. A Google Cloud Pub/Sub topic listens to mailbox changes and sends push webhook notices directly to /api/webhooks/gmail/push.

  • Google Service Account Auth: Incoming webhooks are validated against Google audience JWT claims.
  • Java 21 Virtual Threads: High-throughput asynchronous email reading via spring.threads.virtual.enabled=true.
  • Header Reconstruction: Parses forwarded email headers (From, Subject) for users forwarding from any client.
Component: GmailWebhookService · Google Cloud Pub/Sub
Phase 02 · Smart Engine

Hybrid Deterministic & AI Parser

A @Primary decorator (SmartExtractionService) intercepts emails before invoking costly LLMs, checking for standard templates.

  • LinkedIn & Indeed Parsing: Zero-cost deterministic parsing with sub-millisecond execution and 0ms AI latency.
  • URL Decelerator: Decodes next= parameters from redirect links (e.g. Indeed), shrinking URLs from 220+ to ~50 characters.
  • Safety Disclaimer Filter: Strips security notices (e.g. "without an interview") and review metadata to prevent status pollution.
  • Multi-Model AI Fallback: Unmatched recruiter emails route to Gemini 2.5 Flash Lite with Groq and OpenRouter fallbacks.
Component: SmartExtractionService · TemplateParser · Gemini
Phase 03 · State Machine

Strict Deduplication & Matching

When a parsed application enters JobService.createOrUpdateJob(), it matches against existing active records using strict word-token boundaries.

  • Short-Name Collision Protection: If either company name is ≤ 3 characters (e.g. "MS"), requires exact word tokens rather than loose substring matches.
  • In-Place Lifecycle Promotion: Automatically updates existing records (e.g., Applied → Interview Scheduled) rather than creating duplicates.
  • Timeline Notes: Email snippets and update timestamps are appended directly to transaction logs.
Component: JobService.findBestMatch() · PostgreSQL
Phase 04 · Performance

In-Memory Cache & Reactive Signals

Sub-5ms read speeds achieved with Spring Boot Caffeine in-memory caching and Angular Signals fine-grained reactivity.

  • Caffeine Cache: Caches user profiles, dashboard metrics, and job lists in memory; automatically evicted on mutations.
  • Angular Signals: Optimistic state management updates the board instantly without expensive component tree re-renders.
  • Don't-Drown D3 Scaling: Visually scales small slices (≤2.5% share) so 1 offer among 400 applications remains visible and interactive.
Component: Caffeine Cache · Angular 17 Signals · D3.js

Technical Deep Dive

Engineering Challenges Solved

Event-Driven Gmail Push via Cloud Pub/Sub

Eliminated brittle client-side polling and third-party email forwarder bottlenecks. Connected directly to Gmail OAuth2 and Google Cloud Pub/Sub push webhooks, authenticated with Google Service Account audience claims and processed asynchronously via Java 21 Virtual Threads.

Pub/Sub · Virtual Threads · Service Account JWT

Zero-Cost Deterministic Template Routing

Implemented SmartExtractionService as an intercepting proxy. It parses standardized LinkedIn and Indeed application receipts with deterministic regex/DOM rules in sub-milliseconds, bypassing external AI APIs for 90%+ of emails and falling back to Gemini only for unstructured emails.

0ms AI Cost · TemplateParser · UrlParser

Boundary-Safe Word-Token Deduplication

Solved the classic short-name collision problem where 2-3 letter companies (like "MS") incorrectly matched substrings of larger company records (like "ORION SYSTEMS"). Built token-boundary matching rules and transformed the pipeline into an in-place state progression machine.

Exact Token Bounds · State Promotion · Transaction Logs

High-Performance In-Memory Caffeine Caching

Integrated Caffeine Cache on top of Spring Data JPA to store user profiles, dashboard metrics, and job queries in memory. Combined with event-driven cache invalidation on mutations, dashboard read latencies dropped to sub-5ms while protecting the database.

Caffeine Cache · Sub-5ms Read Latency · Eviction on Mutation

Hybrid Security & Atomic R2 File Operations

Engineered a dual authentication architecture supporting standard JWT credentials and OAuth2 (Google & GitHub) with rotating HTTP-only refresh cookies. Integrated Cloudflare R2 object storage with transactional cleanup of orphaned media files.

Spring Security 6 · OAuth2 · Cloudflare R2 Garbage Collection

"Don't-Drown" D3 Scaling & Reactive Signals

Standard donut charts make rare pipeline states (e.g. 1 offer out of 400 applications) unclickable lines. Developed a geometry scaling algorithm giving small slices a minimum 2.5% visual width while retaining 100% mathematical precision in tooltips, powered by Angular Signals.

Angular Signals · D3.js Geometry Scaling · Optimistic UI

Contributor-Friendly by Design

Zero API Keys Required for Local Dev

JobTrackerPro features environment profiles that allow any developer to clone and run the full stack locally with a single Docker command. When running in the local profile, the backend automatically uses MockGeminiService and local file storage, with a local MailHog SMTP trap for email simulation.

# 1. Start Docker local infrastructure (PostgreSQL & MailHog)
docker-compose up -d
# 2. Start Spring Boot API (Uses local mock AI & local storage)
cd backend && ./mvnw spring-boot:run
# 3. Start Angular frontend
cd frontend && npm start
