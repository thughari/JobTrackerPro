Technical Capabilities

Architected for Production Performance

Explore the design choices and engineering patterns that power JobTrackerPro.

Smart Hybrid Extraction

Routes LinkedIn and Indeed templates through local deterministic parsers, saving 100% of AI cost and latency. Complex emails seamlessly cascade to Gemini 2.5 Flash, Groq, and OpenRouter.

Real-Time Gmail Push

Eliminates slow polling. Google Cloud Pub/Sub sends instantaneous push notifications directly to our backend, authenticated with Google Service Account audience verification and Virtual Threads.

Caffeine In-Memory Caching

Spring Boot in-memory Caffeine cache handles user profiles, dashboard analytics, and application lists. Automatic cache eviction on write operations ensures instant sub-5ms responses.

Strict Word-Token Deduplication

Specialized token-boundary algorithm prevents short company names (≤3 characters like "MS") from colliding with other listings. Updates existing entries in-place with appended timeline notes.

D3.js Donut Slice Scaling

Custom "Don't-Drown" D3 algorithm scales tiny slices (e.g. 1 offer out of 400 applications) up to 2.5% display size so they are visible and clickable, while preserving 100% exact numerical accuracy in tooltips.

Hybrid Security & R2 Storage

Supports both Google/GitHub OAuth2 and JWT email/password with secure rotating HTTP-only refresh cookies. Profile media and career resources are stored in Cloudflare R2 with atomic orphan cleanup.
