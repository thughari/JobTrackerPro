Privacy Policy

Last updated: March 11, 2026

1. Introduction

Welcome to JobTrackerPro. JobTrackerPro is a productivity tool that helps users automatically track their job applications by organizing and analyzing job-related updates.

This Privacy Policy explains what information is collected, how it is used, and how it is protected when you use the application. The system is designed with a privacy-first approach, ensuring that only the minimum data required to provide the service is accessed and processed.

By using JobTrackerPro, you agree to the practices described in this policy.

2. Information I Collect

Account Information

When you authenticate via Google or GitHub, I collect your name, email address, and profile picture to establish your user identity.

Application Metadata

Data you provide about your job applications (e.g., Company, Role, Status, Salary) is stored in a private database record linked only to your account.

Google API Services User Data Policy

JobTrackerPro's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy , including the Limited Use requirements.

Gmail Access: If you enable Gmail integration, JobTrackerPro requests the gmail.readonly scope to read job-related emails such as application confirmations, recruiter outreach, interview invitations, and hiring updates.

Email Processing: Email content is processed temporarily to extract structured job metadata such as company name, job role, status, and relevant links. The original email body is not stored in the database.

AI Processing: Relevant email text may be processed using Google AI services to extract structured job information. This processing is transient and used only to populate the user's job tracking dashboard.

Data Minimization: Using the gmail.labels and gmail.settings.basic scopes, the application creates a dedicated Gmail label named "JobTrackerPro". Only emails matching this label are processed, ensuring unrelated personal emails are never accessed.

No Destructive Actions: The application never sends, deletes, or modifies user emails. Gmail access is strictly read-only.

User Control: Gmail integration is optional and can be disabled at any time from the user's profile settings. Disconnecting Gmail removes stored refresh tokens and stops all Gmail access.

3. How I Use Your Information

Data is used strictly to provide the core functionality of the app:

  • Automating Data Entry
  • Visualizing Analytics
  • Secure Authentication
  • No Data Selling

4. Data Storage & Security

Database: All structured data is stored in a secure PostgreSQL instance managed by Supabase.

Images: User avatars and uploaded resources are stored in Cloudflare R2 buckets.

5. Your Rights & Deletion

You own your data. You may delete individual application records at any time. To permanently delete your entire account and all associated tokens (including Gmail refresh tokens), you can use the "Delete Account" option in your Profile settings. This action is irreversible.
